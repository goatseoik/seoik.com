# 2차고사 영어 · 10월 모의고사

첨부 자료 `2026년 10월 고1 모의고사 유튜브 필기용.pdf`(매튜쌤의 영어수업)의 본문과 해석을 사용합니다. 자료의 요지·해석은 학습 자료이며 새 문제는 이를 바탕으로 만든 변형문제입니다.

- 범위: 18~24번, 29~45번. 41~42번과 43~45번은 각각 공통 지문으로 묶습니다.
- 주제·요지·순서: 지문별 1문항씩, 총 63문항.
- 문장별 영어 빈칸·해석 빈칸: 184개 문장에 각각 1문항씩, 총 368문항. 편지의 인사말·서명과 40번의 별도 요약문은 본문 문장 수에서 제외합니다. 대화의 짧은 감탄은 이어지는 발화와 묶습니다.
- 단원별 학습에서는 직접 입력 후 자동 채점합니다. 필요하면 보기를 펼쳐 선택할 수도 있습니다. 대소문자·띄어쓰기를 정규화하고 원문의 표현과 비교합니다. 다른 번역 표현은 자동 정답으로 처리하지 않습니다.
- 기존 시험지·실전 모의고사·오답노트와 호환되도록 모든 문항에 선택지·정답·해설을 제공합니다. 실전 모의고사와 시험지에서는 선택형으로 풉니다.

`october-2026-source.json`은 문장별로 대응시킨 영어·우리말 데이터입니다. 내용을 수정한 뒤 저장소 루트에서 `python3 tools/build_english_october.py`로 실행 데이터를 재생성하고 `node --test tests/*.test.cjs`로 검증합니다. 기존 영어 세트 뒤에 추가해 기존 세트 번호와 학습 기록을 유지합니다.
