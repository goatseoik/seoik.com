# 2차고사 영어 · 10월 모의고사

영어 본문은 `2026년 10월 고1 모의고사 유튜브 필기용.pdf`(매튜쌤의 영어수업), **해석은 추가로 첨부한 `해석.pdf`(2026학년도 10월 고1 전국연합학력평가 정답 및 해설)를 기준**으로 합니다. 주제·요지·순서 문제는 이를 바탕으로 만든 변형문제입니다.

- 범위: 18~24번, 29~45번. 41~42번과 43~45번은 각각 공통 지문으로 묶습니다.
- 주제·요지·순서: 지문별 1문항씩, 총 63문항.
- **문장·해석 빈칸**: 21개 지문의 184개 문장을 영어 한 줄·해석 한 줄로 나란히 이어서 보여 줍니다. 각 줄의 핵심어가 동시에 빈칸으로 바뀌며, 문장 속에 바로 입력합니다. 총 368칸입니다.
- 개념노트의 채점·정답 보기·다시 풀기·끄기를 사용합니다. Enter는 같은 문장의 영어 빈칸에서 해석 빈칸으로, 이어서 다음 문장으로 이동합니다. 대소문자·공백·문장부호는 기존 개념노트와 같이 정규화합니다.
- 접근: 2차고사 → 영어 → 단원별 학습 → 모의고사 · 문장·해석 빈칸. 영어 개념노트에서도 같은 화면을 열 수 있습니다.
- 지문의 모든 빈칸을 맞히고 채점하면 해당 학습 완료가 저장됩니다. 기존 영어·해석 세트의 번호와 완료 기록은 보존하며, 실전 모의고사와 오답 복습용 선택형 데이터도 유지합니다.
- 편지의 인사말·서명과 40번의 별도 요약문은 본문 문장 수에서 제외합니다. 대화의 짧은 감탄은 이어지는 발화와 묶습니다.
- 해석의 PDF 줄바꿈과 순서·지칭 문항 기호는 정리하되 표현은 원자료를 따릅니다. 30번·42번은 ‘오답 → 정답’ 중 교정된 표현을 사용하며, 기존 필기용 영어 본문에 없는 35번의 무관 문장 해석은 문장별 학습에서 제외합니다.

`october-2026-source.json`은 문장별로 대응시킨 영어·우리말 데이터입니다. `october-2026-translation-reference.json`에는 새 PDF에서 추출한 해석 구간을 보관해 21개 지문 전체의 일치 여부를 대조합니다. 내용을 수정한 뒤 저장소 루트에서 `python3 tools/build_english_october.py`로 실행 데이터를 재생성하고 `node --test tests/*.test.cjs`로 검증합니다.
